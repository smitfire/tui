# `@smitfire/tui`

Claude Code / `agy`-style interactive terminal UX plugin and MCP UI formatter for DeepSeek Harness (`ns-dsh`). Built strictly on public DSH Cordis APIs (`@deepseek-ai/dsh-agent`, `@deepseek-ai/dsh-commands`, `@deepseek-ai/dsh-user-approval`, `@deepseek-ai/dsh-user-questions`, `@deepseek-ai/dsh-tools`, `@deepseek-ai/dsh-session`) with zero core monkeypatching.
